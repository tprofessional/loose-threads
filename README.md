# Loose Threads

A branching interactive game about the lifecycle of a single garment.

## Concept

The player controls one piece of clothing as it moves through:
manufacturing → retail → ownership → resale → secondhand use or disposal.

Player decisions affect the garment's eventual fate.

## Core mechanic

Everyday decisions create downstream consequences.
